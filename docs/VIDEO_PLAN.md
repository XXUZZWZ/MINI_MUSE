# 视频企划：MinMuse，一封邮件讲清楚 Agent

## 标题备选

- 5分钟，从零做一个会读收件箱并每天发摘要的 AI Agent
- 我把 Muse 的“后台 Agent”想法缩成了一个 Python 邮件机器人

## 核心承诺

用一个小仓库讲透 Agent 最小闭环：定时触发、读取邮件、调用模型整理、通过 SMTP 给自己发日报；不搭复杂 Agent 框架，不把危险的自动回复藏在演示里。

## 4分30秒节奏

- 0:00–0:25 痛点与成片效果：每天打开邮箱，先收到一封整理好的摘要。
- 0:25–0:55 Muse 的启发：后台持续做事；涉及外发动作要有边界。说明 MinMuse 是独立教学实现，不是 Meta Muse 的复刻。
- 0:55–1:35 画出闭环：cron → IMAP → LLM → JSON/Markdown → SMTP。
- 1:35–2:15 看收件箱模块：只读未读邮件、限制条数、跳过附件、BODY.PEEK 不改已读状态。
- 2:15–3:00 看 Agent 模块：邮件是输入资料，不是命令；模型只返回结构化摘要和分类。
- 3:00–3:35 看发送闸门：dry-run 默认；`--send` 与环境开关双确认；收件人锁定为自己的邮箱。
- 3:35–4:10 本地假邮件演示：运行 `python -m minmuse --demo`，展示生成的日报。
- 4:10–4:35 阿里云部署方法：独立目录、环境变量、cron；不改动原有提醒程序。
- 4:35–4:50 GitHub 开源邀请：结构、复现步骤、下一步扩展。

## 观众看完能复现

```text
python -m minmuse --demo
```

无需真实邮箱、API key 或网络请求。
